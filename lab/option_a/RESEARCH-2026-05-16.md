## Cross-validated punch list (all 3 agents converged)

| # | Move | Source | Expected gain | Difficulty | Notes |
|---|---|---|---|---|---|
| 1 | **Skibinski WRT preprocessing** | cmix `preprocess/dictionary.cpp`, all 3 agents | **5–10%** on enwik9 | low | Pre-mixer pass, no Cython needed. Static ~80k-word dict → 1–3 byte codes. Symmetric: decoder also loads the dict. |
| 2 | **AC precision 2^16 → 2^24** | Nacrith (arXiv:2602.19626) | **0.05–0.15 bpb free** | trivial | One constant change, no decode-time penalty. Eliminates ~75% of quantization overhead. |
| 3 | **Indirect context model** | cmix `models/indirect.cpp` | 2–4% | medium | Hashed context → shared bit-history slot. Generalizes better than direct counts. |
| 4 | **Nonstationary state map** | cmix `states/nonstationary.cpp` | 1–3% | medium | 32-bit hash → 1-byte state encoding bit history. Compounds with #3. |
| 5 | **APM / SSE final stage** | cmix `mixer/sse.cpp` | 1–2% | low | Final probability-refining table indexed by (context, quantized_p) → trained output. |
| 6 | **Bit-level prediction** | structural prerequisite | enables #3–5 | high | Move from byte-level (256-way) to bit-level (8 binary predictions per byte). All cmix-class predictors are bit-level. |
| 7 | **Bracket/XML-aware model** | cmix `models/bracket.cpp` | 0.5–1% (enwik specifically) | low | Wikitext is XML-shaped. |
| 8 | **Sparse logit bias** | StateSMix (arXiv:2605.02904 §3) | 0.1–0.3 bpb | low | `δⱼ = λ log(1 + cⱼ/α)` for non-zero counts only. O(observed) not O(vocab). |
| 9 | **Article reordering** | fx2-cmix, starlit | ~1.5% | low (offline) | Sort articles by topic similarity for better context coherence. One-shot pre-pass. |
| 10 | **Long-range n-grams (k=16, 32)** | StateSMix | 1–4% | low | 2^24 slots, hash-chained with sliding eviction. Catches Wikipedia template structure. |
| 11 | **Outlier-aware tokenization** | L3TC (arXiv:2412.16642) | 0.5–1% | low | Bypass low-confidence bytes through a separate flat-coded channel. |

## What to skip

- **DeepMind LM-as-compressor (arXiv:2309.10668)** — adjusted ratios catastrophic (14,000% on enwik9 with Chinchilla)
- **ts_zip / FineZip 8B / AlphaZip** — closed-source or too large for Hutter decode budget
- **StateSMix Mamba alone** — 2.12 bpb on enwik8 is uncompetitive; only the sparse-bias + n-gram tricks transfer
- **LSTM byte mixer in Cython** — high cost for 1–3% gain. NumPy/MLX path only if pursued.

## Decode-time reality (Cython feasibility)

Hutter cap: 70,000 / T_geekbench5 hours. Reference Lenovo i7-1165G7, T≈1427 → **49 hours**.

- Pure Python: ~11,000 hours. Dead.
- Cython with `nogil` + typed memviews + raw arrays, no Python in hot loop: **10–40 hours realistic** for cmix-class predictor stack.
- Rust would buy 2-3x headroom. Not strictly mandatory.
- Apple Neural Engine int8 path (for any neural component): bit-exact across M1/M2/M3/M4, deterministic by construction.

**Mandatory discipline:**
1. Hot path 100% `nogil`, typed memviews, no Python attribute access, no tuple/dict/list per-bit
2. State tables as `uint8_t*` / `uint32_t*` in contiguous memory
3. Arithmetic coder in pure Cython (carry propagation, normalization)
4. Use `cython.parallel.prange` only for parallel model probability gathering, not the AC itself
5. WRT preprocessing in Python is fine (one-shot pre-pass)
6. No LSTM mixer in Cython — that's a NumPy/MLX/JAX call

## Revised Phase 2 (replaces prior PLAN.md Phase 2)

Combined target: **3.0 → ~1.6 bpb on 100KB** (a 2x compression gain).

| Sub-phase | Move | Time | Expected gain |
|---|---|---|---|
| 2A | AC precision 2^16 → 2^24 | 1 hour | 0.05–0.15 bpb |
| 2B | WRT preprocessing (build dict + integrate pre-pass) | 1 week | 5–10% on enwik9 |
| 2C | Bit-level codec refactor | 1–2 weeks | 0% (prerequisite) |
| 2D | Indirect context + nonstationary state map | 1–2 weeks | 3–7% combined |
| 2E | APM/SSE final stage | 3 days | 1–2% |

**Phase 3+ candidates (after 2 lands):**
- Higher-order sparse contexts (order-5/6/8 byte-level + bit-level sparse): 1–2%
- Bracket-aware model: 0.5–1% on enwik9
- Long-range 16/32-gram tables: 1–4%
- Article reordering offline: ~1.5%
- Stemmer + NLP word-type tags (fx2-cmix): 0.3–0.5%

**Phase 6+ (research track, separate line):**
- L3TC fork — RWKV-12M + outlier bypass + ANE int8 (4–8 wk, ~1.0 bpb, plausibly top-20)
- NNCP port to MLX int8 (6–10 wk, ~0.85 bpb, possibly Hutter-feasible)
- fx2-cmix + RWKV hybrid (8–12 wk, ~0.85 bpb, top-7 ceiling)
